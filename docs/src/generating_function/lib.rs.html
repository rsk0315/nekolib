1//! 母関数を考える際に必要となる操作。
2//!
3//! ## Notations
4//!
5//! $`n`$ 次多項式 $`f(x) = \sum_{i=0}^n a_ix^i`$ に対し、$`[x^i]\, f(x) = a_i`$ とする。
6//! $`\gdef\e{\mathrm e}`$
7//! $`\gdef\d{\mathrm d}`$
8//!
9//! ## Basics
10//!
11//! $`a(x) = \sum_{i=0}^n a_ix^i`$ かつ $`b(x) = \sum_{i=0}^n b_ix^i`$ とする。
12//! ```math
13//! \begin{aligned}
14//! [x^i]\, \frac{a(x)}{1-x} &= \sum_{j=0}^i a_j, \\
15//! [x^i]\, \bigl(a(x)\cdot b(x)\bigr) &= \sum_{j=0}^i a_jb_{i-j}
16//! \end{aligned}
17//! ```
18//!
19//! すなわち、累積和や畳み込みは多項式の演算に対応すると見なせる。
20//!
21//! $`\sum`$ の添字の入れ替えを悩まずできると吉。
22//!
23//! ```math
24//! \begin{aligned}
25//! \sum_{i=L}^R f(i) &= \sum_{i=L+1}^{R+1} f(i-1)
26//! = f((L+1)-1) + f((L+2)-1) + \dots + f((R+1)-1), \\
27//! \sum_{i=L}^R f(i) &= \sum_{R-i=0}^{R-L} f(L+(R-i))
28//! = f(L+0) + f(L+1) + \dots + f(L+(R-L)) \\
29//! &= \sum_{R-i=0}^{R-L} f(R-(R-i))
30//! = f(R-0) + f(R-1) + \dots + f(R-(R-L)).
31//! \end{aligned}
32//! ```
33//!
34//! ## Convolution-like
35//!
36//! $`a_i = a^{\leftarrow}_{n-i}`$ とする。
37//!
38//! ```math
39//! \begin{aligned}
40//! \sum_{i=0}^n \left(\sum_{j=i}^n a_jb_{j-i}\right)x^i
41//! &= \sum_{i=0}^n \left(\sum_{j=i}^n a^{\leftarrow}_{n-j}b_{j-i}\right)x^i \\
42//! &= \sum_{i=0}^n \left(\sum_{n-j=0}^{n-i} a^{\leftarrow}_{n-(i+n-j)}b_{(i+n-j)-i}) \right) x^i \\
43//! &= \sum_{i=0}^n \left(\sum_{n-j=0}^{n-i} a^{\leftarrow}_{(n-i)-(n-j)}b_{n-j}) \right) x^i \\
44//! &= \sum_{n-i=0}^n \left(\sum_{n-j=0}^{n-i} a^{\leftarrow}_{(n-i)-(n-j)}b_{n-j}) \right) x^i \\
45//! &= \sum_{i'=0}^n \left(\sum_{j'=0}^{i'} a^{\leftarrow}_{i'-j'}b_{j'} \right) x^{n-i'} \\
46//! &= \sum_{i=0}^n \left([x^i]\, \bigl(a^{\leftarrow}(x)\cdot b(x)\bigr) \right) x^{n-i}. \\
47//! \end{aligned}
48//! ```
49//!
50//! ## Operations
51//!
52//! ### Reciprocal
53//!
54//! $`f(x)\cdot g(x) \bmod x^k = 1`$ なる $`g(x)`$ を求める。
55//!
56//! ### Square root
57//!
58//! $`g(x)^2 \bmod x^k = f(x)`$ なる $`g(x)`$ を求める。
59//!
60//! ### Exponential
61//!
62//! 下記で定義される $`\exp(f(x))`$ に対して、$`\exp(f(x))\bmod x^k`$ を求める。
63//! ```math
64//! \exp(f(x)) = \sum_{n=0}^{\infty} \frac{f(x)^n}{n!}.
65//! ```
66//!
67//! ### Logarithm
68//!
69//! $`[x^0]\, f(x) = 1`$ なる $`f`$ に対し、$`\log(f(x)) \bmod x^k`$ を求める。
70//! ```math
71//! \log(1-f(x)) = -\sum_{n=1}^{\infty} \frac{f(x)^n}n.
72//! ```
73//!
74//! $`\tfrac{\d}{\d x} \log(f(x)) = f'(x)\cdot f(x)^{-1}`$ や
75//! $`\log(f(x)\cdot g(x)) = \log(f(x)) + \log(g(x))`$ などが成り立つ。
76//!
77//! ### Power
78//!
79//! $`f(x)`$ と $`k`$ に対して $`f(x)^k`$ を求める。
80//! $`f(x)^0 = 1`$ および、$`k\ne 0`$ に対して $`0^k = 0`$ が成り立つ。
81//!
82//! 以下、$`f(x)\ne 0`$ かつ $`k\ne 0`$ とする。
83//! ある $`l`$ と $`g(x)`$ に対して $`f(x) = a_l x^l\cdot(1+g(x)\cdot x)`$ が成り立つので、
84//! ```math
85//! \begin{aligned}
86//! f(x)^k
87//! &= \bigl(a_lx^l\cdot (1+g(x)\cdot x)\bigr)^k \\
88//! &= a_l^k x^{lk} \cdot (1+g(x)\cdot x)^k \\
89//! &= a_l^k x^{lk} \cdot \exp(k\cdot \log(1+g(x)\cdot x))
90//! \end{aligned}
91//! ```
92//! により求められる。
93//!
94//! ### Circular
95//!
96//! $`\cos(f(x))`$ および $`\sin(f(x))`$ を求める。
97//!
98//! ### Polynomial equation
99//!
100//! $`f(y) \equiv 0 \pmod{x^k}`$ なる $`y`$ を求める。
101//! $`(y, k) \mapsto f(y)\cdot f'(y)^{-1} \bmod x^k`$ の oracle を用いる。
102//!
103//! ### First-order derivative equation
104//!
105//! $`y' \equiv f(y, x) \pmod{x^k}`$ を満たす $`y(x)`$ を求める。
106//! $`(y, k) \mapsto (f(y, x) \bmod x^k, f'(y, x) \bmod x^k)`$ の oracle を用いる。
107//!
108//! ### Relaxed multiplication
109//!
110//! $`f(x)`$ と $`g(x)`$ に対し、$`(f\cdot g)(x) = f(x)\cdot g(x)`$ を求める。ただし、$`[x^i]\, f(x)`$
111//! や $`[x^i]\, g(x)`$ は、各 $`0\le j\lt i`$ における $`[x^j]\, (f\cdot g)(x)`$
112//! を用いて計算されるとする。
113//!
114//! たとえば、与えられた $`\varphi`$ に対して $`\e^{\varphi}`$ を求めるのは、下記の微分方程式を解くことに帰着できる。
115//! ```math
116//! \e^{\varphi} = \int \varphi' \e^{\varphi}.
117//! ```
118//! $`f = \varphi'`$ かつ $`g = \e^{\varphi}`$ として relaxed multiplication を行い、 $`i\gt 0`$
119//! に対して $`[x^i]\, g(x) = i^{-1}\cdot [x^{i-1}]\, (f\cdot g)(x)`$ とすればよい。
120//!
121//! $`\mathrm C_n \mathrm H_{2n+1} \mathrm{OH}`$ の形で表されるアルコールの立体異性体の個数は
122//! ```math
123//! s(z) = 1 + z\cdot \frac{s(z)^3 + 2s(z^3)}3
124//! ```
125//! として $`[z^n]\, s(z)`$ として表せることが Pólya によって示されている。$`[z^0]\, s(z)^3 = 1`$
126//! であり、$`i\gt 0`$ に対して
127//! ```math
128//! \begin{aligned}
129//! [z^i]\, s(z) &= [z^{i-1}] \left(3^{-1}\cdot s(z)^3 + 2\cdot 3^{-1}\cdot s(z^3)\right) \\
130//! &= 3^{-1}\cdot [z^{i-1}]\, s(z)^3 + 2\cdot 3^{-1}\cdot [z^{i-1}]\, s(z^3) \\
131//! &= 3^{-1}\cdot [z^{i-1}]\, s(z)^3 + 2\cdot 3^{-1}\cdot [z^{(i-1)/3}]\, s(z) \\
132//! \end{aligned}
133//! ```
134//! なので…？
135//!
136//! ```math
137//! f(z) = z\cdot\left(1+f{\left(\frac z{1+z}\right)} - z^4 f'(z)^2\right)
138//! ```
139//! が $`O(n\log(n)^3\log(\log(n)))`$ 時間で解けるらしい。
140//! ```math
141//! f(z) = z + f(z^2+z^3)
142//! ```
143//! が $`\tilde O(n)`$ 時間？で解けるらしい。
144//! ```math
145//! f(z) = z + f(z f(z) + z^2 f'(z)) + z^4\exp(z f''(z))
146//! ```
147//! が $`O(n^{3/2}\log(n)^{5/2}\log(\log(n)))`$ 時間で解けるらしい。
