17//! ### Probability spaces
18//!
19//! 集合 $`S`$ の部分集合族 $`\Sigma`$ が $`S`$ 上の **$`\sigma`$-代数** (*$`\sigma`$-algebra*)
20//! であるとは、以下の 3 つの条件を満たすことをいう。
21//! - $`S\in\Sigma`$,
22//! - $`F\in\Sigma \implies \compl{F}\in\Sigma`$,
23//! - 任意の $`I\subseteq\N`$ に対し、$`\{F_n\}_{n\in I}\subseteq\Sigma \implies \bigcup_{n\in I} F_n\in\Sigma`$.
24//!
25//! $`I\subseteq\N`$ を任意に取り、$`i\in I`$ に対して $`\F_i`$ を $`S`$ 上の $`\sigma`$-代数とする。このとき、$`\bigcup_{i\in I} \F_i`$ は $`\sigma`$-代数となる。$`\mathcal C`$ を $`S`$ の部分集合族とするとき、$`\sigma(\mathcal C)`$ で $`\mathcal C`$
26//! を含む最小の $`\sigma`$-代数を表す。これは、そのようなすべての $`\sigma`$-代数の共通部分として定義される。
27//! $`\R`$ のすべての開集合を含む最小の $`\sigma`$-代数を $`\B(\R)`$ と書き、*Borel $`\sigma`$-algebra* と呼ぶ。
28//!
29//! 関数 $`\mu\colon\Sigma\to[0\lldot+\infty]`$ が **$`\sigma`$-加法的** (*$`\sigma`$-additive*)
30//! であるとは、次の 2 つの条件を満たすことをいう。
31//! - $`\mu(\emptyset) = 0`$,
32//! - $`(i, j)\in \binom I2 \implies F_i\cap F_j = \emptyset`$ かつ $`\bigcup_{n\in I} F_n \in \Sigma`$ なる任意の $`I\in\N`$ に対し、$`\mu(\bigcup_{n\in I} F_n) = \sum_{n\in I} \mu(F_n)`$.
33//!
34//! $`\Sigma`$ を $`S`$ 上の $`\sigma`$-代数とする。このとき $`(S, \Sigma)`$ を **可測空間**
35//! (*measurable space*) という。$`\Sigma`$ 上の $`\sigma`$-加法的関数 $`\mu`$ を **測度**
36//! (*measure*) といい、$`(S, \Sigma, \mu)`$ を **測度空間** (*measure space*) という。
37//!
38//! 測度空間 $`(\Omega, \F, \P)`$ が $`\P(\Omega) = 1`$ を満たすとき、$`\P`$ を **確率測度**
39//! (*probability measure*) といい、$`(\Omega, \F, \P)`$, $`\P(\Omega)`$ を **確率空間**
40//! (*probability space*) という。$`\F`$ に含まれる集合を **事象** (*event*) という。
41//!
42//! <span style="font-size: 75%">Caratheodory の拡張定理と、拡張の一意性を述べる必要がありそう。</span>
43//!
44//! ### Random variables
45//!
46//! $`(S, \Sigma, \mu)`$ を可測空間とし、$`\B = \B(\R)`$ とする。
47//!
48//! $`h\colon S\to\R`$ とし、$`A\subseteq \R`$ に対して $`h^{-1}(A) = \{s\in S\mid h(s)\in A\}`$
49//! と定義する。任意の $`B\in\B`$ に対して $`h^{-1}(B)\in\Sigma`$ となるとき、$`h`$
50//! は **$`\Sigma`$-可測** (*$`\Sigma`$-measurable*) であるという。$`\Sigma`$-可測な関数を
51//! $`m\Sigma`$ と書く。そのうち、非負のものと有界のものを、それぞれ $`(m\Sigma)^+`$
52//! および $`b\Sigma`$ と書く。
53//!
54//! 確率空間 $`(\Omega, \F, \P)`$ 上の可測関数<span style="font-size: 75%">（$`\F`$-可測な関数？）</span>を
55//! **確率変数** (*random variable*) という。
56//!
57//! $`X\colon\Omega\to\R`$ を $`(\Omega, \F, \P)`$ 上の確率変数とする。*the law of $`X`$* は
58//! $`\L_X = \P\circ X^{-1}`$ で、$`(\R, \B)`$ 上の確率測度である。$`\L_X`$ は、
59//! **$`X`$ の分布関数** (*distribution function of $`X`$*) $`F_X(x) = \P[X\le x]`$
60//! ($`x\in\R`$) で定められる。
61//!
62//! ### Independence
63//!
64//! $`(\Omega, \F, \P)`$ を確率空間とする。
65//!
66//! $`\F`$ の部分 $`\sigma`$-代数 $`\mathcal G_1, \mathcal G_2, \dots`$ が **独立**
67//! (*independent*) であるとは、任意の相異なる $`i_1, i_2, \dots, i_n`$ に対して
68//! ```math
69//! \P[G_{i_1}\cap\dots\cap G_{i_n}] = \prod_{j=1}^n \P[G_{i_j}]
70//! ```
71//! が成り立つことをいう。ただし、任意の $`i\in\N`$ に対して $`G_i\in\mathcal G_i`$
72//! とする。確率変数 $`X_1, X_2, \dots`$ が独立であるとは、$`\sigma`$-代数
73//! $`\sigma(X_1), \sigma(X_2), \dots`$ が独立であることをいう。
74//!
75//! 事象 $`E_1, E_2, \dots`$ が独立であるとは、$`\mathcal E_i = \{\emptyset, E_i, \compl{E_i}, \Omega\}`$
76//! で定義される $`\sigma`$-代数 $`\mathcal E_1, \mathcal E_2, \dots`$ が独立であることをいう。
77//!
78//! <span style="font-size: 75%">*independent and identically distributed* について触れる必要がありそう。</span>
79//!
80//! ### Expectation
81//!
82//! $`(S, \Sigma, \mu)`$ を可測空間とする。集合 $`A`$ 上の **特性関数**
83//! (*characteristic function*) を
84//! ```math
85//! \1_A(x) = \begin{cases}
86//! 1, & \text{if~}s\in A; \\
87//! 0, & \text{if~}s\notin A
88//! \end{cases}
89//! ```
90//! で定義する。**単関数** (*simple function*) とは、次の形で書ける関数のことをいう。
91//! ```math
92//! f = \sum_{k=1}^m a_k\cdot\1_{A_k}.
93//! ```
94//! ただし、各 $`k`$ に対し $`a_k\in[0\lldot+\infty]`$ かつ $`A_k\in\Sigma`$
95//! とする。単関数全体からなる集合を $`\mathrm{SF}^+`$ と書く。$`f`$ の **積分** (*integral*) を
96//! ```math
97//! \mu(f) = \sum_{k=1}^m a_k\cdot\mu(A_k)
98//! ```
99//! で定義する。
100//! <span style="font-size: 75%">$`\mu\colon \mathrm{SF}^+\ni f\mapsto \mu(f)\in\R`$ と、$`\mu\colon \Sigma\ni A_k\mapsto \mu(A_k)\in[0\lldot+\infty]`$ が混在していてややこしい。</span>
101//!
102//! 関数 $`f`$ に対し、$`f^+`$ と $`f^-`$ でそれぞれ $`f`$ の正・負の部分を表す。
103//! ```math
104//! f^+(s) = \max{\{f(s), 0\}}, \qquad f^-(s) = \max{\{-f(s), 0\}}.
105//! ```
106//! $`|f| = f^+ + f^-`$ に注意せよ。$`\mu(f^+) + \mu(f^-) \lt +\infty`$
107//! であるとき、$`\mu(f) = \mu(f^+) - \mu(f^-)`$ と定義する。
108//!
109//! $`(\Omega, \F, \P)`$ を確率空間とする。非負の確率変数 $`X`$ に対し、$`P`$ 上の $`X`$
110//! の積分を $`\E[X]`$ と書き $`X`$ の **期待値** (*expectation*)
111//! という。一般に、$`\E[X^+] + \E[X^-] \lt +\infty`$ のとき
112//! $`\E[X] = \E[X^+] - \E[X^-]`$ と定義する。そのような **可積分な確率変数**
113//! (*integrable random variables*) 全体からなる集合を $`L^1(\Omega, \F, \P)`$ と書く。
114//!
115//! $`X\colon\Omega\to\R_{\ge 0}`$ が
116//! ```math
117//! X(\omega) = \sum_{E\in\F} x_E\cdot \1_E(\omega)
118//! ```
119//! の形で書けるとして、
120//! ```math
121//! \E[X] = \P(X) = \sum_{E\in\F} x_E\cdot \P(E)
122//! ```
123//! と定義されるということ？

135//! ## Examples
136//!
137//! ### Markov chain
138//!
139//! 有限個の状態からなる集合 $`Q = \{q_0, q_1, \dots, q_{n-1}\}`$ を考える。
140//! 時刻 $`t`$ に状態 $`q_i`$ にいるとき、時刻 $`t+1`$ に確率 $`p_{i, j}`$ で
141//! $`q_j`$ に遷移する。各 $`i`$ に対して $`\sum_j p_{i, j} = 1`$ が成り立つ。
142//! 各遷移は独立に行われるものとする。
143//!
144//! 状態 $`q_0`$ にいる状態から開始し、初めて $`q_{n-1}`$ に到達する時刻の期待値を求めよ、という問題を考える。
145//!
146//! まず、$`j \le i \implies p_{i, j} = 0`$ の問題設定について考える。
147//! 時刻 $`0`$ に状態 $`q_i`$ にいるとき、初めて状態 $`q_{n-1}`$ に到達する時刻を $`X_i`$
148//! とする。最終的な答えは $`\E[X_0]`$ である。
149//!
150//! 定義から明らかに $`\E[X_{n-1}] = 0`$ である。時刻 $`0`$ に状態 $`q_i`$
151//! にいるとし、時刻 $`1`$ に各状態にいる確率を考えることで
152//! ```math
153//! \begin{aligned}
154//! \E[X_i] &= 1 + \sum_{j=0}^{n-1} p_{i, j}\cdot \E[X_j] \\
155//! &= 1 + \sum_{j=0}^i 0\cdot \E[X_j] + \sum_{j=i+1}^{n-1} p_{i, j}\cdot \E[X_j] \\
156//! &= 1 + \sum_{j=i+1}^{n-1} p_{i, j}\cdot \E[X_j] \\
157//! \end{aligned}
158//! ```
159//! を得る。すなわち、$`\E[X_i]`$ の計算のために必要な値は $`i \lt j`$ なる $`j`$ における
160//! $`\E[X_j]`$ と $`p_{i, j}`$ のみであるため、$`i`$ の降順に計算することで $`\E[X_0]`$
161//! を求められる。
162//!
163//! 続いて、$`j \lt i \implies p_{i, j} = 0`$ かつ $`i\lt n-1\implies p_{i, i} \in[0\lldot 1)`$
164//! の問題設定について考える。$`X_i`$ の定義は先ほどと同様とする。
165//! ```math
166//! \begin{aligned}
167//! \E[X_i] &= 1 + \sum_{j=0}^{n-1} p_{i, j}\cdot \E[X_j] \\
168//! &= 1 + \sum_{j=0}^{i-1} 0\cdot \E[X_j] + \sum_{j=i}^{n-1} p_{i, j}\cdot \E[X_j] \\
169//! &= 1 + p_{i, i}\cdot \E[X_i] + \sum_{j=i+1}^{n-1} p_{i, j}\cdot \E[X_j], \\
170//! (1-p_{i, i})\cdot \E[X_i] &= 1 + \sum_{j=i+1}^{n-1} p_{i, j}\cdot \E[X_j], \\
171//! \E[X_i] &= \frac1{1-p_{i, i}}\cdot\left(1 + \sum_{j=i+1}^{n-1} p_{i, j}\cdot \E[X_j]\right) \\
172//! \end{aligned}
173//! ```
174//! よって、先ほどと同様に $`i`$ の降順に計算して $`E[X_0]`$ を求められる。
175//!
176//! 続いて、一般の場合について考える。ただし、任意の $`i`$ について、状態 $`q_i`$
177//! から開始して有限時間で状態 $`q_{n-1}`$ に遷移できるような遷移の仕方が存在するものとする。各
178//! $`i\lt n-1`$ についての $`\E[X_i] = 1 + \sum_j p_{i, j}\cdot \E[X_j]`$ を線形方程式系と見なせるので
179//! ```math
180//! \begin{aligned}
181//! \left(\begin{matrix}
182//! 1-p_{0, 0} & -p_{0, 1} & \cdots & -p_{0, n-2} & -p_{0, n-1} \\
183//! -p_{1, 0} & 1-p_{1, 1} & \cdots & -p_{1, n-2} & -p_{1, n-1} \\
184//! \vdots & \vdots & \ddots & \vdots & \vdots \\
185//! -p_{n-2, 0} & -p_{n-2, 1} & \cdots & 1-p_{n-2,n-2} & -p_{n-2,n-1}
186//! \end{matrix}\right)
187//! \times
188//! \left(\begin{matrix}
189//! \E[X_0] \\
190//! \E[X_1] \\
191//! \vdots \\
192//! \E[X_{n-2}] \\
193//! 0
194//! \end{matrix}\right)
195//! =
196//! \left(\begin{matrix}
197//! \;0\; \\
198//! 0 \\
199//! \vdots \\
200//! 0
201//! \end{matrix}\right),
202//! \end{aligned}
203//! ```
204//! すなわち
205//! ```math
206//! \begin{aligned}
207//! \left(\begin{matrix}
208//! 1-p_{0, 0} & -p_{0, 1} & \cdots & -p_{0, n-2} \\
209//! -p_{1, 0} & 1-p_{1, 1} & \cdots & -p_{1, n-2} \\
210//! \vdots & \vdots & \ddots & \vdots \\
211//! -p_{n-2, 0} & -p_{n-2, 1} & \cdots & 1-p_{n-2,n-2}
212//! \end{matrix}\right)
213//! \times
214//! \left(\begin{matrix}
215//! \E[X_0] \\
216//! \E[X_1] \\
217//! \vdots \\
218//! \E[X_{n-2}]
219//! \end{matrix}\right)
220//! =
221//! \left(\begin{matrix}
222//! \;0\; \\
223//! 0 \\
224//! \vdots \\
225//! 0
226//! \end{matrix}\right)
227//! \end{aligned}
228//! ```
229//! を解けば（あるいは、解けないことを示せば）よい。
230//! 対角成分が正、それ以外が非正であることからなにかが言える？
231//!
232//! 行列が特殊な形をしている場合は、掃き出し法などを介さずとも前述のように解くことができる。
233//! See also [ABC 189 F](https://atcoder.jp/contests/abc189/tasks/abc189_f).

235//! ## Techniques
236//!
237//! ### Probability
238//!
239//! 非負整数の値を取る確率変数 $`X`$ に対して、
240//! ```math
241//! \begin{aligned}
242//! \E[X] &= \sum_{i=0}^{\infty} i\cdot\Pr(X = i) \\
243// &= \sum_{i=1}^{\infty} \sum_{j=i}^{\infty} \Pr(X=j) \\
244//! &= \sum_{i=0}^{\infty} i\cdot(\Pr(X\ge i) - \Pr(X\gt i)) \\
245//! &= \sum_{i=0}^{\infty} i\cdot\Pr(X\ge i) - \sum_{i=0}^{\infty} i\cdot\Pr(X\ge i+1) \\
246//! &= \sum_{i=1}^{\infty} i\cdot\Pr(X\ge i) - \sum_{i=1}^{\infty} {(i-1)\cdot\Pr(X\ge i)} \\
247//! &= \sum_{i=1}^{\infty} \Pr(X\ge i)
248//! \end{aligned}
249//! ```
250//! が成り立ち、$`\Pr(X = i)`$ を求める問題から $`\Pr(X\ge i)`$ を求める問題に帰着できる。
251//!
252//! また、何らかの条件を満たすまで何らかの操作を繰り返すことを考える。操作を完了するまでの回数の期待値を求めたい。
253//!
254//! $`i`$ 回目の操作が行われるとき $`X_i = 1`$、そうでないとき $`X_i = 0`$ となる確率変数 $`X_i`$
255//! を考える。高々 $`n`$ 回で完了する確率を $`p(n)`$ とすると、求める期待値は
256//! ```math
257//! \begin{aligned}
258//! \E{\left[\sum_{i=1}^{\infty} X_i\right]}
259// &= \E{\left[\sum_{i=0}^{\infty} {(1-p(i))}\right]}
260//! &= \sum_{i=1}^{\infty} \E[X_i] \\
261//! &= \sum_{i=1}^{\infty} {(0\cdot p(i-1) + 1\cdot(1-p(i-1)))} \\
262//! &= \sum_{i=0}^{\infty} {(0\cdot p(i) + 1\cdot(1-p(i)))} \\
263//! &= \sum_{i=0}^{\infty} {(1-p(i))} \\
264//! \end{aligned}
265//! ```
266//! である。操作回数を表す確率変数を $`X`$ とすると $`\P(X\le i) = p(i)`$ なので、先の補題より
267//! ```math
268//! \begin{aligned}
269//! \E[X] &= \sum_{i=1}^{\infty} \P(X\ge i) \\
270//! &= \sum_{i=1}^{\infty} {(1-\P(X\lt i))} \\
271//! &= \sum_{i=1}^{\infty} {(1-\P(X\le i-1))} \\
272//! &= \sum_{i=0}^{\infty} {(1-\P(X\le i))} \\
273//! &= \sum_{i=0}^{\infty} {(1-p(i))} \\
274//! \end{aligned}
275//! ```
276//! とすることもできる。
277//!
278//! See also [ABC 331 G](https://atcoder.jp/contests/abc331/tasks/abc331_g).

280//! ### Powers
281//!
282//! 各 $`i\in\Lambda_n`$ に対して $`X_i \in \{0, 1\}`$ となるような確率変数 $`X_i`$
283//! を考える。ただし、各 $`X_i`$ 同士は独立とは限らないとする。これに対し、
284//! ```math
285//! \E{\left[\left(\sum_{i=0}^{n-1} X_i\right)^2\,\right]}
286//! ```
287//! を求めたいとする。
288//! ```math
289//! \begin{aligned}
290//! \E{\left[\left(\sum_{i=0}^{n-1} X_i\right)^2\,\right]}
291//! &= \E{\left[\sum_{i=0}^{n-1} X_i^2 + 2 \sum_{i=0}^{n-1} \sum_{j=i+1}^{n-1} X_i X_j\right]} \\
292//! &= \sum_{i=0}^{n-1} \E{\left[X_i^2\right]} + 2 \sum_{i=0}^{n-1} \sum_{j=i+1}^{n-1} {\E[X_i X_j]} \\
293//! &= \sum_{0\le i\lt n} \Pr(X_i = 1) + 2 \sum_{0\le i\lt j\lt n} \Pr(X_i = X_j = 1)
294//! \end{aligned}
295//! ```
296//! より、$`\sum_{0\le i\lt n} \Pr(X_i = 1)`$ や $`\sum_{0\le i\lt j\lt n} \Pr(X_i = X_j = 1)`$
297//! を求める問題に帰着できる。より一般には、$`\E[(\sum_{i=0}^{n-1} X_i)^M]`$ は、各
298//! $`1\le m\le M`$ に対する
299//! ```math
300//! \sum_{(i_0, \dots, i_{m-1}) \in \binom{\Lambda_n}{m}} \Pr{\left(\bigwedge_{j=0}^{m-1} X_{i_j} = 1\right)}
301//! ```
302//! の線形和を求める問題に帰着できる。係数は Stirling partition number になる。
303//!
304//! DP などで、任意の $`0\le i_0\lt i_1\lt \dots \lt i_{m-1}\lt n`$ にわたる
305//! $`\Pr(X_{i_0} = X_{i_1} = \dots = X_{i_{m-1}} = 1)`$ の総和を求められる場合は、これを利用するのがよいであろう。
306//!
307//! See also [ABC 277 G](https://atcoder.jp/contests/abc277/tasks/abc277_g).
